# System Architecture & Documentation (VipCar CRM)

Цей файл описує, як працює система, щоб уникнути дублювання та неправильних архітектурних рішень.

## 1. Загальний Стек
- **Фреймворк**: Next.js 15 (App Router, Server Actions).
- **База даних**: Prisma + SQLite (dev.db) / PostgreSQL (production).
- **Стилізація**: Tailwind CSS, власні класи в `index.css`.
- **Авторизація**: NextAuth.js (email/password).

## 2. Логістика та Калькулятор (Smart Fuel Logistics)
Калькулятор (`src/components/Calculator.tsx`) розраховує ціну на основі складної логіки:
1. Отримує координати та дистанцію через **OSRM** + **Nominatim** (з `accept-language=uk`).
2. **Алгоритм "Де дешевше"** (`src/lib/fuelCalculator.ts`):
   - Аналізує список країн маршруту (напр. Україна, Польща).
   - Шукає ціну пального в глобальних налаштуваннях (`FuelPrice`).
   - Сортує країни по зростанню ціни.
   - Заправляє авто в найдешевшій країні в межах `fuelTankVolume` (мінус 20% похибки). Залишок літрів добирає у наступних (дорожчих) країнах.
3. Враховує: Зарплату водія (ставка * км), Амортизацію, Відстань доїзду (Delivery), Вартість палива (Smart Fuel) та Чистий прибуток.

## 3. Бекенд Ланцюжки Маршрутів (`src/lib/chaining.ts`)
Коли авто їде у рейс, воно залишається в місті прибуття. `recalculateChain(carId)` сортує всі бронювання авто в хронологічному порядку і рахує, скільки потрібно доїзду (expenseDeliveryDistance) від завершення попереднього рейсу до початку нового. Ця ж логіка перераховує витрати на пальне (через Smart Fuel Calculator).

## 4. Telegram Інтеграція (Особистий Userbot)
Ми **не використовуємо класичних ботів (через BotFather)** для основного спілкування!
- Використовується **MTProto Userbot** (`gramjs` у `src/lib/telegramClient.ts`).
- Userbot авторизований на **особистому акаунті Адміністратора** (через телефон та код).
- Коли клієнт або водій пише Адміну в особисті повідомлення (або коли бот отримує вебхук), повідомлення потрапляє в базу `ChatRoom` і `Message`, і відображається в CRM у вкладці `/admin/chat`.
- Адмін відправляє повідомлення з CRM, і воно летить клієнту/водію напряму від імені Адміна.

## 5. Водії та Повідомлення
- Модель `Driver` має `telegramId` (поки буде додано).
- Водії існують як `User` з `Role = DRIVER` і прив'язаним `Driver` профілем.
- Водії заходять на `/driver` для перегляду своїх рейсів.
- Для автоматичних сповіщень: водій повинен першим написати Адміну в Телеграм (щоб відкрити чат і уникнути спам-блокувань Telegram), Адмін бачить його ID в Чатах CRM і прив'язує цей ID до профілю Водія.
- При призначенні рейсу система бере `telegramId` і відправляє деталі через `telegramClient.sendMessage()`.
