# Розрахунок Зарплати Водія та Доїзд до Клієнта

## Мета
Реалізувати точний розрахунок зарплати водія за кілометри, включаючи відстань "доїзду" авто (від бази до точки посадки клієнта). Доїзд для клієнта залишається як додаткова вартість (коефіцієнт), а для водія — це чисті робочі кілометри, які оплачуються за його ставкою (наприклад, 0.15€/км).

## Запропоновані Зміни

### 1. База Даних (Prisma Schema)
- **[MODIFY]** `prisma/schema.prisma`
  - Додати поле `deliveryDistance Float @default(0)` до моделі `Booking`. Це дозволить зберігати точну кількість кілометрів доїзду для кожної поїздки.

### 2. Калькулятор (Клієнтська частина)
- **[MODIFY]** `src/components/Calculator.tsx`
  - При розрахунку витрат на водія: `costDriver = (distance + calcDeliveryDist) * 0.15;` (де `calcDeliveryDist` — це розрахована відстань від Бази до точки старту клієнта).
  - У функцію створення бронювання передати параметр `deliveryDistance: Math.ceil(calcDeliveryDist)`.

### 3. API Бронювання
- **[MODIFY]** `src/app/api/bookings/route.ts`
  - Приймати та зберігати `deliveryDistance` під час створення нового бронювання.

### 4. Дашборд та Зарплата Водія
- **[MODIFY]** `src/app/driver/page.tsx` та `src/app/driver/settlements/page.tsx`
  - Зарплата за конкретний рейс буде розраховуватись як: `(booking.distance + booking.deliveryDistance) * driver.salaryPerKm`.
  - Додати відображення "Доїзду" в інтерфейсі водія, щоб він бачив, за що йому нараховуються ці кілометри.

> [!IMPORTANT]
> Наразі "Пункт старту авто" (База) береться з глобальних налаштувань (GPS координати бази). Чи потрібно вам мати можливість **вручну змінювати точку старту авто** для кожної поїздки в адмін-панелі (наприклад, якщо авто знаходиться в іншому місті)? Або ж автоматичного розрахунку від Бази до Клієнта достатньо?

## План Перевірки
1. Згенерувати клієнт Prisma.
2. Протестувати бронювання через калькулятор.
3. Перевірити відображення зарплати в панелі водія (Сума = (Маршрут + Доїзд) * Ставка).
